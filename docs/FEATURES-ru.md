# Kernel 0.4.1 — Windows x64

Настольный браузер на Chromium / Electron. Интерфейс — чёрный, серый и белый, без фоновых иллюстраций и градиентов. Чат называется просто «Чат»; интерфейс использует системный шрифт Segoe UI.

## Профили, разрешения и полный экран

Нажми на профиль внизу слева, чтобы открыть аккаунт. Можно создать локальный аккаунт с паролем, войти по имени или ID, изменить имя, аватар и пароль. Минимальная длина пароля — 8 символов. При переключении аккаунта браузер перезапускается и восстанавливает вкладки выбранного профиля. Вкладки, настройки, cookies, история, закладки и переписка чата разделены между аккаунтами. Создание аккаунта из гостя сохраняет данные этого гостевого профиля за новым аккаунтом.

Это локальные аккаунты: регистрации на сервере и синхронизации между компьютерами нет. Пароли хранятся как scrypt-хеши с индивидуальной солью. Запомненный вход защищён хранилищем Windows. Это не шифрование всех файлов браузера и не защита от администратора самого компьютера.

У владельца может быть отдельный профиль разработчика, подтверждённый цифровой подписью. Публичная сборка не содержит личных аккаунтов, аватаров, паролей, сессий или приватных ключей. Локальные аккаунты не переносятся на другие компьютеры автоматически.

Полноэкранное видео открывается без диалога разрешения и занимает всё окно: верхняя панель, вкладки и правая панель скрыты. Esc возвращает обычный вид. Запросы камеры/микрофона, геолокации и уведомлений тоже не показываются: по умолчанию доступ запрещён, его можно включить в настройках конфиденциальности. Файлы по умолчанию сохраняются в папку загрузок без диалога; выбор папки для каждого файла можно вернуть в настройках. Системный UAC Windows для запуска обхода остаётся.

## Оформление

Существующая структура сохранена. Закреплённые вкладки — компактные кнопки с иконками сайтов; обычные вкладки — список с мягким фоном активной строки и тонким индикатором. Чтобы открепить или закрыть закреплённую вкладку, используй правый клик; средняя кнопка мыши закрывает вкладку.

Верхняя панель уменьшена до 48 px, правая панель инструментов — до 38 px. Убраны лишние разделители и рамки. Основные поверхности стали почти чёрными. Чат находится справа. Внизу слева — профиль; DEV отображается только у владельца. Настройки цветов, шрифтов, плотности и ширины панелей сохранены.

## Запуск готовой сборки

Для отправки другим используй один файл `Kernel-0.4.1.exe`. Его можно запускать без установки и прав администратора. При запуске он извлекает ресурсы во временную папку. Данные аккаунтов сохраняются отдельно в `%APPDATA%\Kernel` и остаются после закрытия. Установка Node.js, Ollama или Python не нужна. Для первого запуска ИИ нажми «Скачать модель» в чате: потребуется интернет и примерно 2,5 ГБ места. Затем чат работает локально.

На этом компьютере можно продолжать запускать `Kernel.exe` из папки `Kernel`: модель уже лежит рядом. Эту папку держи целиком. Для передачи другим предпочтителен отдельный exe выше; личные данные из `%APPDATA%\Kernel` передавать не нужно.

Модель — Qwen3-4B, 4 миллиарда параметров. Нужны Windows 10/11 x64, современный процессор и желательно от 8 ГБ свободной оперативной памяти. Автоматический режим использует видеокарту через Vulkan, при невозможности запуска переключается на CPU. В настройках можно выбрать режим вручную. При открытии чата установленная модель заранее загружается в память. По умолчанию выгружается после 15 минут бездействия; время можно изменить. Интернет нужен браузеру для сайтов, но не локальному чату после загрузки модели.

## Что работает

- Реальные веб-страницы Chromium, поиск и адресная строка, переход назад/вперёд и обновление.
- Вкладки слева, закрепления сверху, перетаскивание вкладок в своей группе, отключение звука и дублирование через правый клик.
- Сохранение сессии, cookies, истории и закладок между запусками. Неактивные восстановленные вкладки загружаются после выбора.
- Скрываемая правая панель ИИ: локальный чат, потоковый ответ, остановка генерации, форматирование кода и новый диалог.
- «Использовать страницу»: передать текст и выделение активной страницы локальному помощнику. По умолчанию выключено. На правый клик по выделенному тексту доступно «Объяснить с ИИ»; перед отправкой запрос можно изменить.
- Помощник умеет предлагать открытие сайтов; переход выполняется после нажатия отдельной кнопки пользователем.
- Закладки, история, загрузки с выбором пути сохранения, настройки поисковой системы, компактная панель вкладок и DNS через HTTPS.
- Встроенный zapret 1.10.3 от Flowseal с выбором всех стратегий из релиза и кнопками включения/выключения.

## Настройки

Открой шестерёнку справа, меню → «Настройки» или нажми Ctrl + запятая. Изменения сохраняются автоматически в прежний профиль.

- Основные: запуск, домашняя страница, новая вкладка, Google / DuckDuckGo / Bing / Яндекс, кнопка домой, масштаб и проверка орфографии.
- Оформление: тёмная, светлая и системная темы, своя палитра, акцент, установленный шрифт, размер текста, плотность и скругление, ширина панелей, скрытие правой панели, элементы новой вкладки.
- Конфиденциальность: история, Google / Cloudflare DNS через HTTPS, разрешения камеры/микрофона, геолокации и уведомлений, сброс запомненных решений. Очистка кеша, cookies/данных сайтов и истории выполняется только после выбора в диалоге; переписка чата и настройки сохраняются.
- Загрузки: папка и выбор сохранения каждого файла. При автоматическом сохранении существующие файлы не перезаписываются.
- ИИ: CPU / Vulkan / авто, предварительная загрузка, время в памяти, контекст, длина и вариативность ответа.

Поиск по странице — Ctrl F; Enter / Shift Enter переключают совпадения. Печать — Ctrl P.

На этом компьютере (i5-10400F, RTX 2060 SUPER 8 ГБ) один и тот же тест на 96 выходных токенах показал 4,75 токена/с на прежнем CPU-режиме и 45,60 токена/с на Vulkan после прогрева. Это примерно 9,6 раза быстрее в данном тесте; размер запроса и загрузка компьютера влияют на результат. Измерения — `performance.json`, скрипт — `scripts/benchmark.cjs`.

## Обход

Справа нажми щит → «Дополнительно: DPI / zapret» → выбери стратегию → «Включить обход». Подтверди системный запрос Windows. Kernel запускает свой экземпляр winws/WinDivert, показывает фактическое состояние процесса и останавливает его при выключении или закрытии браузера. При аварийном завершении браузера отдельный наблюдатель завершает принадлежащий ему процесс. Постоянный автозапуск не устанавливается.

WinDivert влияет на подходящий сетевой трафик компьютера, включая другие приложения. Это DPI-обход, а не VPN: он не меняет IP-адрес. Если сайт не открывается, выключи обход и попробуй другую стратегию. Не запускай параллельно несколько копий zapret. Релиз проверен 7 октября 2026 года; доступность у конкретного российского провайдера требует проверки в его сети. Положение «Запущен» означает работающий процесс, а не гарантию разблокировки.

Исходный проект: https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.3 . Kernel не меняет hosts, системный прокси и настройки антивируса.

## Данные и устройство

Данные находятся в `%APPDATA%\Kernel`. Новые профили используют отдельные каталоги `profiles` и отдельные разделы Chromium. `accounts.json` содержит имена, ID, аватары и хеши паролей, `account-session.json` — защищённый токен запомненного входа. История и вкладки хранятся в `browser.json` соответствующего профиля, cookies — в разделе Chromium, история чата — в локальном хранилище интерфейса. «Новый диалог» очищает сохранённую переписку. Контекст страницы передаётся только при включённом переключателе и отправке сообщения. Если после отправки сменить вкладку, модель продолжит работать со снимком страницы на момент отправки.

Сайты работают в отдельных sandbox-процессах без Node.js и без системного моста Kernel. Управление окнами, AI и обходом доступно только доверенному локальному интерфейсу. Локальный сервер модели слушает только 127.0.0.1, защищён случайным ключом и завершается вместе с приложением. Ссылки file:, javascript:, data: и протоколы внешних приложений из адресной строки не запускаются.

## Ограничения

Это ранняя сборка, ещё не замена зрелому браузеру для всех задач. Нет магазина расширений, синхронизации, менеджера паролей, автообновления и лицензированного Widevine DRM. Некоторые сайты с проверкой поддерживаемого браузера, авторизацией Google в embedded-окнах или защищённым видео могут не работать. TLS-проверки не отключаются. Скорость и совместимость не сравнивались в бенчмарках с Firefox/Chrome.

Локальный чат использует Qwen3-4B. Она может ошибаться и не имеет самостоятельного поиска в интернете. Для разговора используются последние сообщения с ограничением объёма; длинные страницы сокращаются. Инструмент открытия сайта всегда ждёт нажатия пользователем.

## Запуск из исходников

Потребуются Windows x64 и Node.js 22 или новее.

```powershell
npm ci
npm run prepare-vendor
node scripts/download-parallel.cjs
npm start
```

Файлы модели загружаются рядом с проектом в `../models`, проверяется SHA-256. Если исходники извлечены отдельно без весов, можно также скачать модель кнопкой в чате. Для сборки с включёнными весами сначала запусти скрипт выше, затем `npm run build`.

```powershell
npm test
npm run smoke
```

`npm run build:share` создаёт отдельный exe без встроенных весов модели. Для проверки переключения аккаунтов: `electron . --account-smoke-test <абсолютный-путь-к-отдельной-тестовой-папке>`. Проверка создаёт тестовые аккаунты и выполняет несколько настоящих перезапусков.

Smoke-проверка создаёт отдельный профиль и локальный HTTP-сервер, открывает настоящие страницы Chromium, проверяет вкладки, изоляцию страниц, панель AI, контекст и реальные ответы включённой модели. Она не включает WinDivert и не изменяет сеть Windows.

Сведения о сторонних лицензиях и исходных проектах: `THIRD-PARTY-NOTICES.md`, `vendor/provenance.json`. Собственный код Kernel распространяется по MIT.

## Утилиты и локальный архив

Кнопка </> на правой панели открывает утилиты. Ctrl+K или Ctrl+Shift+P — поиск по всем командам. Структура браузера сохранена.

Сохранение страницы: Snapshot (без выполнения скриптов), Editable Copy (HTML/CSS/JS), Single HTML (ресурсы внутри одного файла). Папка — sites на рабочем столе Windows, включая перенесённый в OneDrive рабочий стол. У каждой копии index.html, capture.json с исходным URL и ошибками, preview.png; в отдельных форматах есть assets. Журнал показывает реальные FETCH/WRITE/SKIP, доступна отмена. Копия содержит клиентскую часть, а не серверный код, авторизацию, DRM или закрытые API. Недоступные ресурсы перечислены в capture.json. Лимит: 600 ресурсов, 40 МБ на ресурс, 300 МБ суммарно. Canvas, закрытые shadow DOM и динамические серверные функции могут потребовать ручной доработки.

В разделе страницы: выбор элемента мышью, HTML/CSS, Tailwind, размеры, цвета и шрифты; пипетка; скриншоты всей страницы, области и элемента; PDF статьи или исходной страницы; режим чтения; список ресурсов с выбором скачивания; ссылки, QR, Markdown, URL-заметки и локальная правка текста, CSS и картинок. Esc отменяет выбор. Обновление отменяет временную правку. Сравнение снимков показывает изменения текста. Размер PNG ограничен 16000 × 32760 px. Reader использует Mozilla Readability и DOMPurify.

В разработке: JSON-дерево с поиском и копированием пути; API Inspector с URL, method, status, headers, timing и телом до 500 КБ. Запись запросов включается вручную и хранится только в памяти, максимум 200 запросов. Authorization/Cookie/token headers скрыты; тело ответа может содержать данные самой страницы. Cookies/localStorage/sessionStorage можно посмотреть и очистить отдельно. Разрешения сайта меняются без всплывающих запросов. Redirect Tracker использует историю перехода текущей вкладки или реальный HEAD-запрос.

Responsive Preview — реальные Chromium viewport для телефона, планшета и ноутбука (до трёх одновременно); верхняя строка закрывает просмотр. Split View показывает другую открытую вкладку рядом. Focus скрывает интерфейс, Esc возвращает его. PiP+ для прямого HTTP(S) video открывает отдельное окно с размером, прозрачностью и режимом поверх окон; blob/MSE-потоки используют обычный Chromium PiP и его стандартные возможности.

Для вкладок: дубликаты, выгрузка неактивных вкладок из памяти, сохранение и восстановление workspace. В загрузках доступны поиск, фильтр состояния, pause/resume для поддерживающих это загрузок и повтор. Поиск в адресе: tabs: github, history: kernel, bookmarks: design. История clipboard содержит только тексты, явно скопированные внутри Kernel; она очищается при выходе. Quick Convert поддерживает единицы, дату, JSON, Base64/URL и курсы валют с датой обновления. Архив ищет сохранённые страницы по заголовку, URL и тексту. Открытие копии использует приложение Windows для HTML.

## Kernel Connection

Щит справа: Direct, Smart Route, Secure Tunnel · Tor и Custom Proxy (HTTP, HTTPS CONNECT, SOCKS5 с паролем). Собственный сервер для Tor не нужен. В комплекте официальный Tor 0.4.9.13 и транспорт Snowflake. Первое подключение может занять несколько минут; скорость Tor обычно ниже прямого соединения. Доступность зависит от текущей сети. Это маршрутизация вкладок Chromium, не весь набор защит Tor Browser.

Маршрут применяется к вкладке, точному hostname сайта, workspace или всему Kernel. Приоритет: явный маршрут вкладки → правило сайта → workspace → общий маршрут. Smart использует эти правила; без правила — Direct. При смене маршрута страница перезагружается. Разные маршруты используют разные Chromium sessions/cookies, поэтому сайт может попросить войти заново. Обычные вкладки сохраняют прежнюю Direct-сессию.

Kill Switch включён: отказ защищённого маршрута блокирует загрузку; Auto fallback пробует другой настроенный профиль, не Direct. Явное отключение Kill Switch разрешает Direct при отказе. Кнопка Use Direct делает переключение вручную. Tor запускается по требованию и завершается вместе с Kernel; системный VPN и прокси не изменяются. Смена DNS через HTTPS доступна в настройках Connection; через SOCKS5 имя назначения передаётся прокси. WebRTC UDP вне защищённого маршрута запрещён. Диагностика IP выполняет реальный запрос через текущий маршрут, IP скрыт до Reveal; поле DNS описывает политику, а не отдельный тест утечки. Пароли прокси зашифрованы хранилищем Windows и не попадают в журнал или состояние интерфейса.

## Установщик

Kernel-Setup-0.4.1.exe — отдельный установщик с оформлением Kernel: тёмные поверхности, Segoe UI, свой экран приветствия и завершения. Выбирается папка установки, создаются ярлыки рабочего стола и меню «Пуск», добавляется удаление через «Установленные приложения» Windows. Установка выполняется для текущего пользователя без прав администратора. При обновлении и обычном удалении сохраняется %APPDATA%\Kernel. Личные профили, аватар владельца и приватные ключи в установщик не входят.

Модель чата не включена в установщик: она скачивается отдельно при первом использовании и затем работает локально. Kernel появляется в списке доступных браузеров Windows для HTTP/HTTPS. Назначение по умолчанию остаётся выбором пользователя. Внешняя ссылка открывается в уже запущенном Kernel. Сборка: npm run build:installer. Для запуска без установки остаётся Kernel-0.4.1.exe.
