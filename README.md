# Kernel Browser

<img src="assets/kernel.svg" width="64" alt="Kernel Browser">

Браузер для Windows x64 на Chromium / Electron: вертикальные вкладки, локальный ИИ, инструменты для работы со страницами и Kernel Connection. Компактный интерфейс в тёмных тонах, с настройкой цветов, шрифтов и плотности.

**Поддержка в Discord: `tripleg.hvg`.** Ошибки и предложения можно также оставлять в [Issues](https://github.com/Oguzzok-mj/kernel-browser/issues).

## Скачать

- [Установщик Kernel 0.4.2 для Windows x64](https://github.com/Oguzzok-mj/kernel-browser/releases/download/v0.4.2/Kernel-Setup-0.4.2.exe)
- [Все файлы релиза](https://github.com/Oguzzok-mj/kernel-browser/releases/tag/v0.4.2)

Закройте Kernel перед установкой обновления. Установщик позволяет выбрать папку, создаёт ярлыки и устанавливает браузер для текущего пользователя. Аккаунты и настройки в `%APPDATA%\Kernel` сохраняются при обновлении и обычном удалении. Сборка пока не подписана цифровым сертификатом.

Локальная модель **Qwen3-4B Q4_K_M** загружается отдельно при первом использовании чата: около **2,5 ГБ**. Затем чат работает на компьютере, через llama.cpp; доступны CPU и Vulkan. Имя и разработчик модели указаны в документации и лицензиях. Контекст страницы передаётся модели только по действию пользователя.

## Браузер

- Вкладки слева: компактные закреплённые иконки, список обычных вкладок, мягкое выделение активной вкладки.
- Чат и утилиты справа; настройки цветов, шрифтов, размеров и плотности интерфейса.
- Локальные аккаунты с паролями, отдельными вкладками, cookies, историей, закладками и перепиской. Синхронизации между компьютерами нет.
- Полноэкранное видео скрывает интерфейс браузера; Esc возвращает его.
- Поиск, закладки, история, загрузки, масштабирование и настройки разрешений сайтов.

## Kernel Connection

- Direct, Smart Route, Secure Tunnel через **Tor**, пользовательские **HTTP / HTTPS CONNECT / SOCKS5** прокси.
- Tor и Snowflake включены в сборку; собственный сервер для Tor не требуется. Доступность зависит от сети, первое подключение может занять несколько минут.
- Правила для вкладки, hostname, workspace или всего браузера; раздельные Chromium sessions для разных маршрутов.
- Kill Switch, переключение на другой настроенный маршрут, диагностика IP, DNS over HTTPS и ограничение WebRTC UDP вне прокси.
- Пароли прокси защищены хранилищем Windows.
- Дополнительный DPI-инструмент zapret запускается отдельно с системным UAC.

Kernel с маршрутизацией Tor не обладает всем набором защит Tor Browser. Tor не является системным VPN. DPI-инструмент действует на компьютер, а маршрутизация Connection применяется к вкладкам Kernel.

## Сборка из исходников

Windows x64, Node.js 22 или новее:

```powershell
npm ci
npm run prepare-vendor
npm start
```

`prepare-vendor` скачивает закреплённые версии llama.cpp, Tor и zapret и проверяет SHA-256. Бинарные зависимости и веса модели не хранятся в Git. Модель можно скачать из чата; для сборки со встроенными весами - `node scripts/download-parallel.cjs`.

```powershell
npm test
npm run build:installer
npm run build:share
```

`build:installer` создаёт установщик, `build:share` - portable EXE, оба без весов модели. Собственный код и конфигурация сборки находятся в этом репозитории.
